## 一、先量（S47，都是真机读数）

| 路径 | 复制 10 份 | 写 20 次文字 | 合计 |
|---|---|---|---|
| **A) DOM 三步舞步**（选中 → 复制 → 改文字，每份 3 个模态边界） | 选中 520 + 复制 435ms | **1440ms** | **2397ms**（≈240ms/份） |
| **B) AM 一次 batchPlay 复制**（按 `_id`，N 条一起发） | **165–188ms（17–19ms/份）** | 一次模态写完 **1128–1209ms（≈56–60ms/次）** | **1293–1397ms** |

**四条事实**（后续设计全部基于它们）：

1. ✅ **AM `duplicate` 按 `_id` 成立且可合批**：一次 batchPlay 发 N 条，**17–19ms/份**（DOM 那套是 95ms/份 + 每份 3 个模态边界）。
2. 🔴 **真正的成本在"写文字"**：DOM `layer.textItem.contents = 值` **≈56–68ms/次**（它是 `textItem` **唯一**可写属性）。
   ⇒ 出稿耗时 ≈ **N × 绑定列数 × 60ms**。面板上要**如实报预估耗时**（20 份 × 4 列 ≈ 5s）。
3. ✅ **改副本不动原件**：10 份规模下复验（原件仍是 `["旧-B","旧-A"]`）—— 这是 M3b 的硬条件。
4. 🔴 **`duplicate()` 之后必须跨一个模态边界才能读到副本的子层**（同一个模态里 `copy.layers` 读到**空数组**，
   第一版探针就这么"改文字 0 次"了）。⇒ 实现必须"复制（一批）→ **新模态**里读写文字"。

## 二、数据流

```
CSV（已有）        +   绑定表（列 → 图层名）   +   模板（用户自己 PSD 里的一个图层组）
        ↓ 点「生成 N 个稿件」
① 一次 batchPlay：AM duplicate × N（按模板组 _id，名字先给「稿件 i」）
② 跨一个模态：读副本 → 按绑定把该行的值写进对应文字层（N × 列数 次 DOM 写）
③ 一次 batchPlay：按 _id 改副本名（带上行值，便于在图层面板里认人）
```

**绑定怎么表达**：`列 → 图层名`（1:1；下拉里允许同一图层被两列选中，等于"一对多"）。
**"图层名"指模板组里的文字图层名** —— 所以模板里图层名要有意义（`标题` / `价格` / `日期`）。

## 三、面板（沿用已选的方向 2 + 列抽屉）

第三个折叠块「按行批量出稿」现在是**占位文字**，换成真控件：

```
┌ 按行批量出稿 ──────────────────── 5 列 · 6 行 ┐
│ 模板  将复制：‹版式 · 价格卡› · 3 个文字层   [重新检测] │
│ 绑定  标题  → [ 标题            ▾ ]              │
│       价格  → [ 价格            ▾ ]              │
│       日期  → [ （不绑定）        ▾ ]              │
│       …                                          │
│ ⚠ 3/5 列已绑定：未绑定的列不会写进版面（不拦你）        │
│ 预估：6 份 × 3 处文字 ≈ 1.1s                      │
└──────────────────────────────────[ 生成 6 个稿件 ]┘
```

- 下拉的候选项 = **扫描当前文档的文字图层**（一次只读遍历，便宜），显示 `图层名 · 前 12 字内容`。
- 列抽屉里也放一份「绑到图层」（与列宽/对齐并列）——**同一份状态，两个入口**。
- 出稿过程要有**进度 + 人能读的日志**（哪一步、第几份），失败原因写在界面上。

## 四、自证方案（沿用 M3a 那套）

- **真机 S48**：自建临时文档（模板组 2 个文字层 + 3 行数据）→ 走面板整链出 3 份 → 读回：
  ① 副本数 = 3 ② **每份的文字 = 对应行**（逐份读回）③ **原件一字没动** ④ 副本名带行值
  ⑤ 耗时与预估对得上。
- **离线**：出稿计划的**纯函数**（行 × 绑定 → "第 i 份的 X 层写什么值"）+ **命令形状**断言
  （duplicate 只按 `_id`、写文字只走 `textItem.contents`、上限闸门）。
- **上限闸门**：N × 列数 超过阈值（比如 400 次写文字 ≈24s）时**先问再出**，不静默截断。
