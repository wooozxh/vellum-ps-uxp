## 二、假 VellumDesk 桩（契约 §11 要求）

契约 §11 要求"两侧都要有假对方，才能各并行开发"。插件侧这一半本次做出来了：

**`tools/fake-vellumdesk.cjs`** —— 往插件 PluginData 写一份**契约合规**的镜像。

```
node tools/fake-vellumdesk.cjs                   写默认镜像
node tools/fake-vellumdesk.cjs --task-rev 88     只改 task revision（测轮询"变了"）
node tools/fake-vellumdesk.cjs --clean           清掉镜像目录
node tools/fake-vellumdesk.cjs --dir <path>      指定 PluginData（默认自动发现）
node tools/fake-vellumdesk.cjs --major 26        指定 PS 大版本（默认 27）
```

它产出：`manifest.json`（总索引 + `scopes[]`）+ `task.json`（1 项目/1 包/V1/2 素材）
+ `brand.json`（2 分组：公司素材 2 + 我的收藏 1）+ `thumb/`（5 张 PNG，纯 JS 编码，不依赖任何图像库）
+ `handoff/`（契约 §六：**目录由软件侧预建**，所以桩也建它）。

> **为什么要重造**：`docs/11` §一 那次探针的假镜像是我**自拟的简化结构**
> （`manifest.json` 里直接塞 brand + projects、缩略图叫 `f1.webp`）。
> 它证明了**能力**，但**不符合契约** —— 而 `mirror.js` 要按契约解析。两者必须对齐才测得准。
>
> ⚠️ 顺带修掉一个自己的 bug：桩第一版的 `generatedAt` 用 `toISOString()` 把 `Z` 直接换成 `+08:00`
> —— **UTC 时间配东八区后缀，差了 8 小时**。契约要求"ISO 8601 带时区"，已改用本地时间构造。

## 三、镜像读取层 `lib/mirror.js`

契约 §八「**写者唯一性**」：`manifest.json` / `task.json` / `brand.json` / `thumb/**` 的写者**只有软件侧**；
插件唯一可写的是 `handoff/req.json`。所以这一层**只读**。

| 导出 | 作用 |
|---|---|
| `readManifest()` | 读总索引；**先校验 `contract === "vellum-link/1"`，不认识就 `unsupported` 降级提示**（不崩、不猜） |
| `readScope(scope)` | 读 `task.json` / `brand.json`，并校验其 `contract` 与总索引一致 |
| `flatten(scopeId, data)` | 树 → **扁平素材列表 + 面包屑**（`task` 走 projects→packs→versions→assets；`brand` 走 groups→assets） |
| `thumbUrl(asset, revision)` | `ArrayBuffer → Blob → objectURL`；**换 revision 时统一 revoke 旧 URL**（防泄漏） |
| `insertPlan(asset)` | 按 `kind`/`ext` 给出插入方案（位图→新图层 / PSD→智能对象 / 视频·PDF→暂不支持） |
| `watch(onChange)` | 每 3 秒读一次 manifest，比对 `scopes[].revision` 签名，变了才回调（契约 §5.1 的算法） |

**三条硬约束写进了代码**（都是实测换来的）：
1. **缩略图必须 png/jpg** —— 读到 `.webp` 直接返回 `{ok:false, webp:true, error:"…"}`，
   附带**可读原因**（"请让软件侧按契约 §5.5 转成 png/jpg"）。宁可在这一层拦住，也不让 UI 出一堆空白格。
2. 承载缩略图的 DOM **必须可见**（`display:none` 里 UXP 不加载图片，表现为"超时"）。
3. 加法兼容：软件侧新增字段，插件**必须忽略不认识的字段**（不在读的时候把 schema 写死）。
