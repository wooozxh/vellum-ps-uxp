# 32 · 置入的图层按素材名命名（v0.3.6）

> 输入（用户）："现在插入的图层名称都是 `incoming`，希望置入的图层能以文件名命名。"
> **拍板**：① **不带扩展名**；② 同名以后缀 **` (n)`** 区分。

---

## 一、根因：图层名来自"被置入文件的名字"

PS 的置入会拿**源文件的名字**当图层名。而契约 §六 规定交接文件是**固定名** `incoming.<ext>`
（每次覆盖 —— 出于"好清理 + 防竞态"），于是每个新图层都叫 `incoming`，图层面板里分不清谁是谁。

> 这也解释了为什么自检里测试文件 `t112.png` 置入后图层就叫 `t112`：**名字跟着文件走**。

## 二、方案：插件侧改名，**不动契约**

名字改从**镜像里的 `asset.name`** 取（就是用户在设计软件里看到的那个名字）
⇒ **不需要任何交接文件的命名规范**，也不用软件侧配合。

流程（`tools/library.js` 第 ⑤ 步）：置入 → 尺寸/位置校正 → **重命名** → 读回验证。

```js
const named = await ps.renameInsertedLayer(a);   // 内部：去重 → 改名 → 读回
```

⚠️ **只在图层真的多出来（`changed`）时才改** —— 万一置入失败，否则会把用户**原有的**图层改掉。

### 命名规则（`lib/ps.js`，三个纯函数）

| 函数 | 职责 |
|---|---|
| `layerBaseName(asset)` | `asset.name` **去掉已知的 `asset.ext`** |
| `uniqueLayerName(base, taken)` | 原名 → `原名 (2)` → `原名 (3)` …（取第一个没被占用的） |
| `fitName(base, suffix, limit)` | 把总长压进 255：**先截基名、再拼后缀**（别把后缀截掉） |

三条细节：

1. **只砍 `asset.ext` 那个后缀**，不用"砍最后一个点"的写法 ——
   名字里带点很常见（`v1.2 终稿`），那样会被砍成 `v1`。
2. **去完扩展名要 `trim()`** —— `报告 .png` 会留下尾空格。（这条是**离线断言抓出来的**：
   8 个用例里就它不对。判据是对的、实现改了，不是把期望值放宽去迁就代码。）
3. 判重名要**递归进组**（`doc.layers[].layers`），不然组里的同名图层会被漏掉。

### 🔴 一处改不掉的（已如实告知用户）

智能对象内部记录的**链接源文件名**仍然是 `incoming.<ext>`。
图层面板显示的是我们设的名字 ✓（用户的主要诉求满足）；但"编辑智能对象内容 / 链接面板"
里露出来的还是 `incoming`。要连那个也改，只能让软件侧**用原文件名交接** ——
那要动契约（固定名是为了清理与防竞态），代价明显更大，**暂不做**。
