# 38 · M3「批量出稿」到底是个什么功能

> 2026-10-11 · 用户问"我不太懂批量出稿是啥" ⇒ 把这块的定义、出处、机制、以及**唯一的歧义点**一次说清。
> 本文只澄清概念，不改代码、不含新实测。

---

## 一、这个词的出处（不是我造的）

| 来源 | 原话 |
|---|---|
| `vellum-toolbox/tools/index.js`（该功能页的占位） | `subtitle: "表格绑定图层，批量出稿"` |
| 设计稿 `A-bento-dark.html` 表格页 | 「把表格的**列**绑定到**图层**，按**行**批量生成**稿件**。」 |
| 设计规范 `B-native-pro-spec.html` | 「**5 列全部绑定**：告警条转为常规灰，主按钮恢复…文案带上真实行数『生成 6 个稿件』」 |
| 同上（对按钮文案的说明） | 「按钮文案带真实行数。『生成 6 个稿件』而不是『生成』—— 点之前就知道会发生什么，**批量操作尤其重要**。」 |

⚠️ 注意规范稿那句"**5 列全部绑定**"：它说明面板上那条黄色**警告行**管的就是
"**每一列都绑定到图层了没有**"。**"绑定"这个词只有在"目标图层已经存在"时才讲得通** ——
这一点决定了下面 §三 的读法。

---

## 二、它是什么（一句话）

> **用一张数据表，套同一个版式，自动出 N 份设计稿。**

- **列 = 数据字段**（标题 / 价格 / 日期 …）
- **行 = 一份稿**（一行一个人 / 一个项目 / 一个课程）
- **绑定 = 告诉插件"这一列的数据要写进哪个图层"**
- 点一次按钮 ⇒ 复制版式 N 次、把 N 行数据分别填进去 ⇒ **N 份同版式、内容各不同的稿**

举你手上的例子：`prices-2026.csv` 有 6 行 ⇒ 点「生成 6 个稿件」⇒
6 张版式一样、只有标题和价格不同的海报（或报价单、证书、朋友圈图）。

**它是 PS 原生「图像 → 变量 → 数据组」的 UXP 版**：
PS 里那套老功能（定义变量 → 导入数据组 → 把数据组导出成文件）干的就是这件事。
⚠️ 但那套 API **UXP 侧调不到**（v0.3.8 的 S33 实测：`doc.dataSets` / `doc.variables` / `app.variables` 全读不到）
⇒ 想做就得自己实现。**我们实测过的替代机制是**：
`选中组 → Layer.duplicate() → 只改副本组里的文字`（S33：副本改了 **且** 原件没变 ✅）。

## 三、唯一的歧义（必须你拍一下）

「把表格的列绑定到图层」里的"**图层**"，指的是哪一种？

| | **读法 A · 套你的版式**（我判断是原本的意思） | 读法 C · 套插件生成的表格 |
|---|---|---|
| 目标图层 | **你自己 PSD 里的图层**（版式模板） | 插件刚生成的那张表的单元格文字层 |
| 你要先做什么 | 先做好一个版式，图层按列命名 | 什么都不用，插件自己造 |
| 产出 | N 份**任意版式**的稿件（海报/报价单/证书…） | N 份"只含某一行"的小表 |
| 用途强度 | **很实用**（多项目同款物料） | 弱（谁会要 6 张单行小表？） |
| 与"绑定/告警"是否自洽 | ✅ 自洽（没绑全就没法出稿） | ❌ 不自洽（表是插件造的，不需要你绑） |

⇒ **读法 A 是唯一能同时解释"绑定"和"警告行"的读法**，也是这个功能真正的价值所在。

---

## 四、如果按 A 做，用户的操作链

```
① 拿到/做好一个版式（PSD，图层名有意义：标题、副标题、价格、日期…）
② 导入 CSV（6 行 × 5 列）
③ 面板上把 5 个列头 逐个绑到 图层   ← 这一屏是新的，也是本功能的核心界面
④ 绑全 ⇒ 警告行变灰、按钮可用（文案带真实行数「生成 6 个稿件」）
⑤ 点生成 ⇒ 6 份稿件（每份一个图层组，排开摆放）
```

**技术上都已具备**（v0.3.8/v0.3.9 实测）：
- 建组 / 复制组 / 逐组换文字 ✅
- 读选区当排版区域 ✅（S36）
- 批量发命令（37.5ms/层）✅
- 文件读写 + utf-8/GBK 解码 ✅

**还缺的只有"绑定界面"和"图层名怎么对得上列名"这两件交互设计上的事** —— 这正好是我下一步出 UI 方向要解决的核心问题。

---

## 五、它和「生成表格」是什么关系

同一个功能页里其实是**两件事**，需要你定要怎么摆：

| | 生成表格 | 批量出稿 |
|---|---|---|
| 输入 | CSV | CSV + **你的版式** |
| 产出 | 一张**可继续编辑的表格**（每格一个文字层 + 矢量线） | N 份**套好数据的稿件** |
| 解决什么 | "我要一张表格物料 / 要个表结构来改" | "我要批量出同款物料" |

**三种摆法**：
1. **只做批量出稿**（表格预览只是"看一眼数据"的辅助，不落 PS）——最聚焦；
2. **两件都做，并列两个按钮**（「生成表格」/「生成 N 个稿件」）——与设计稿骨架一致；
3. **做成一条流水线**：先生成表格当版式 → 再按行出稿 —— 但这样只支持"表格类"版式，**适用范围窄**。

我倾向 **2**（照设计稿骨架），因为"生成表格"本身对"我要一张报价表物料"这种需求也是直接可用的；
但如果你想更聚焦，**1** 也完全合理 —— 请你选。
