## 1. 技术路线速选

| 路线 | 语言 | PS 版本 | 产物 | 状态 | 适用 |
|---|---|---|---|---|---|
| **UXP Plugins**（首选） | JS / HTML / CSS | ≥ 22.0 | `.ccx` | 持续开发 | 面板、模态框等完整插件 |
| UXP Scripts | JS (ES6+) | ≥ 23.5 | `.psjs` | 持续开发 | 快速自动化、批处理 |
| UXP Hybrid | C++ + JS | ≥ 24.2 | `.ccx` | 持续开发 | 高性能 / 原生能力 |
| CEP + ExtendScript | ExtendScript (ES3) | 14–20 | `.zxp` | **已停止开发** | 仅维护旧插件 |
| C++ Plug-in SDK | C++ | CS3+ | DLL/EXE/DMG | 停止开发 | 底层滤镜 / 格式 |
| Photoshop API（云） | 任意 | — | — | 持续开发 | 服务端 REST 批处理 |

**结论**：做本机插件 → **UXP Plugins**；想最快跑通 → 从 **UXP Scripts** 起步；要极致性能 → **Hybrid / C++**。

### 2.4 配置 / Manifest（v5 为当前版本）
- **UXP Manifest v5 规范**（当前版本，需 PS ≥ 23.3 / UXP 6.0+）：https://developer.adobe.com/photoshop/uxp/2022/guides/uxp-guide/uxp-misc/manifest-v5/

- Photoshop Manifest 附录（PS 特有字段与破坏性变更）：https://developer.adobe.com/photoshop/uxp/2022/guides/uxp-guide/uxp-misc/manifest-v4/photoshop-manifest/

**v5 三个必记要点：**
1. 顶层加 `"manifestVersion": 5`，UI 入口用 `entrypoints`（v4 时代叫 `uiEntryPoints`）。
2. **权限默认全关**：没用到的能力一个都不给，必须显式声明 `requiredPermissions`。
3. 权限类型：`network.domains`、`clipboard`、`localFileSystem`(`request`/`plugin`/`fullAccess`)、`launchProcess`、`webview`、`ipc.enablePluginCommunication`、`enableUserInfo`(GUID)。

最小可用 manifest（官方示例精简版）：
```json
{
  "manifestVersion": 5,
  "id": "com.yourname.plugin",
  "name": "My Plugin",
  "version": "1.0.0",
  "main": "index.html",
  "host": { "app": "PS", "minVersion": "23.3.0" },
  "entrypoints": [
    { "type": "panel", "id": "mainPanel", "label": { "default": "My Panel" },
      "minimumSize": { "width": 230, "height": 200 } }
  ],
  "requiredPermissions": {
    "localFileSystem": "request"
  }
}
```

### 3.4 快速上手路径（建议照此推进）
1. 写一个 **UXP Script（.psjs）**：不打包不建工程，直接在 PS 里跑 JS 操作图层 → 熟悉 `app`/`document`/`layer` 对象模型。
2. 用 UDT 建 **vanilla starter**：理解 manifest、entrypoints、面板加载流程。
3. 升级到**框架 starter**（React / Vue / Svelte）：引入 Node 构建链，做复杂 UI。
4. 用 **Alchemist 录 batchPlay** 做真实功能 → 包进 `executeAsModal`。
5. **打包发布**：UDT 一键出 `.ccx`；上架则去 Developer Console 申请正式 ID。

- [x] **Adobe Photoshop** —— ✅ 已装（2026 / v27.2，走 UXP 通道无障碍）

     直链（仍是 CC 深链）：https://creativecloud.adobe.com/apps/download/uxp-developer-tools
- [ ] **代码编辑器** —— ❌ 本机缺 → 推荐 VS Code（`winget install Microsoft.VisualStudioCode`）

### 可选（用框架 / 打包 / AI 直连时才需要）
- [x] **Node.js** —— ✅ v22.22.2（官方建议 LTS 偶数版，已满足；starter 要求 ≥ 14.20.0）
- [x] **npm** —— ✅ 10.9.7（已配 npmmirror 国内镜像）
- [ ] **yarn** —— 无需安装，Node 自带 corepack：`corepack enable`（示例仓库多用 yarn）
- [ ] **TS 类型** —— `npm i -D @adobe-uxp-types/photoshop @adobe-uxp-types/uxp`
- [x] **Python** —— ✅ 3.13.14（adb-mcp 需要）
- [ ] Webpack / Vite —— 随 starter 自带

### 搭建步骤（补齐缺口后照做）
1. **装 CC 桌面端** → 登录 Adobe 账号 → Apps 里装 **UXP Developer Tools**。
2. **启用开发者模式**：首次启动 UDT 会弹窗，点 Enable 并授予管理员权限。
   兜底（需管理员）：在 `%CommonProgramFiles%\Adobe\UXP\Developer\` 建 `settings.json`，内容 `{"developer": true}`。
   同时在 PS 内：**设置 → 插件 → 勾选「启用开发人员模式」**，重启 PS。
3. **建工程**：① UDT 点 `Create Plugin`，Host 选 Adobe Photoshop，模板选 `ps-starter`（vanilla）或 `ps-react-starter`；或 ② 克隆官方示例仓库挑 starter。
4. **加载调试**：保持 PS 运行 → UDT 左侧应出现 "Adobe Photoshop" → 插件行点 `Load`（或 ••• → Load）。
   框架工程注意：指向 **`dist/manifest.json`**，不是源码根目录。
5. **迭代**：Watch 模式下改 HTML/CSS/JS 自动热重载；**改 `manifest.json` 必须 Unload → 重新 Load**。

## 7. 常见坑与备忘

- **改 `manifest.json` 不热重载** → 必须 Unload → 重新 Load。
- **框架工程加载失败** → UDT 里要指向 `dist/manifest.json`，不是源码目录。
- **UDT 连不上 PS** → 确认 PS ≥ 22.0、已开开发者模式、UDT 以管理员身份运行。
- **改文档报错** → 检查是否漏了 `core.executeAsModal()`；模态被占用会返回错误码 9。
- **权限报错** → v5 起权限默认全关，用到的能力必须在 `requiredPermissions` 里声明。
- **依赖版本冲突** → Spectrum 组件跨版本有破坏性变更，建议锁死确切版本号，别用 `^` / `~`。
- **npm/yarn 报错** → 多为 Node 版本不匹配；本机已用偶数版 v22，改 `npm` 兜底。
- **batchPlay 描述符写不出来** → 别硬编，用 Alchemist 录。
- **`import` 报错** → UXP 里引宿主模块用 `require("photoshop")` / `require("uxp")`，不是 ESM。

## 8. 给 AI 的上下文模板（可直接粘贴）

```
【项目】Photoshop UXP 插件开发
【宿主】Photoshop 2026 (27.x)，Windows
【规范】manifest v5；UI 用 HTML/CSS/JS（UXP 子集）+ Spectrum 组件
【硬约束】
1. UXP 不是浏览器也不是 Node：引模块用 require("photoshop") / require("uxp")，不是 import。
2. 任何修改文档的操作必须包在 core.executeAsModal(async () => {...}) 内。
3. DOM API 未覆盖的能力，用 batchPlay 回放 Action Manager 描述符（不要编造 DOM 方法）。
4. 文件/网络/剪贴板/本地存储等权限必须在 manifest 的 requiredPermissions 显式声明。
5. 面板入口用 entrypoints（type: "panel"），命令入口用 type: "command"。
【参考】Photoshop DOM API: developer.adobe.com/photoshop/uxp/2022/ps-reference/
        UXP API: developer.adobe.com/photoshop/uxp/2022/uxp-api/
        Manifest v5: developer.adobe.com/photoshop/uxp/2022/guides/uxp-guide/uxp-misc/manifest-v5/
【产出要求】给出完整可运行文件 + manifest，并标注需要声明的权限。
```
