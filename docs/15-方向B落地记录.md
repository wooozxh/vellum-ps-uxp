## 二、设计令牌

深色 = 设计稿原值，同时贴近 Photoshop 深色主题（面板 `#323232`）；浅色 = 同一套层级关系、明度反转（对照 PS 浅色主题）。

| 令牌 | 用途 | 深色 | 浅色 |
|---|---|---|---|
| `--vt-panel` | 内容底 | `#323232` | `#f0f0f0` |
| `--vt-bar` | 顶栏 / 状态条 | `#2b2b2b` | `#e4e4e4` |
| `--vt-surf` / `--vt-surf2` | 卡片 / 次级卡片 | `#3a3a3a` / `#2e2e2e` | `#ffffff` / `#e8e8e8` |
| `--vt-raised` | hover 底 | `#424242` | `#dcdcdc` |
| `--vt-sink` | 浮层底 | `#262626` | `#d6d6d6` |
| `--vt-line` / `--vt-line2` / `--vt-edge` | 发丝线三档 | `#4a4a4a` / `#3f3f3f` / `#1c1c1c` | `#c4c4c4` / `#d8d8d8` / `#ababab` |
| `--vt-tx` → `--vt-tx4` | 文字四级 | `#e6e6e6` → `#5f5f5f` | `#1a1a1a` → `#8c8c8c` |
| `--vt-ac` / `--vt-ac-hi` | 强调色 | `#1473e6` / `#2e8ff0` | `#1473e6` / `#0d63d0` |
| `--vt-ok` / `--vt-warn` | 状态 | `#4cd07e` / `#e8b65e` | `#1f9d55` / `#b07a1e` |

**切换机制（双保险）**：

1. `@media (prefers-color-scheme: light)` —— 媒体查询路径（若 UXP 支持）；
2. JS 探测后给 `<html>` 挂 `.vt-dark` / `.vt-light` —— **不依赖媒体查询，一定可靠**。
   探测优先 `window.matchMedia`，失败则读 `--uxp-host-background-color` 的亮度，再失败按深色。

> 为什么不全押媒体查询：`prefers-color-scheme` 在 UXP 的支持情况属于**待实测项**（探针第 9 项）。
> JS 路径经离线回归验证（第 5 项：`className = "vt-dark"`），即使媒体查询完全失效界面也完整。

## 三、设计稿 → UXP 的组件映射

| 设计稿 | 实现 | 说明 |
|---|---|---|
| `.grid-template-columns: repeat(3,1fr)` | `flex-wrap` + `width:33.3333%` | Grid 不支持 |
| `.grid-template-columns: repeat(4,1fr)` | `flex-wrap` + `width:25%` | 同上 |
| `place-items:center` | `display:flex` + `align/justify-content:center` | Grid 不支持 |
| `.app::before` 顶部渐变条 | 真实元素 `.brandbar`（2px 纯色） | 伪元素 + 渐变双风险，都避开 |
| `box-shadow: 0 0 0 1px #fff, 0 0 0 2px var(--ac)` | 真实元素 `.sw-ring`（向外扩 2px 的 2px 蓝框） | **色块 hover/选中的唯一反馈载体**，不能丢 |
| `.tip { transform: translateX(-50%) }` | JS 手算 `left` 并 clamp 到容器内 | `transform` 不支持 |
| `transition` 各处 | 全部删除，状态直接切换 | 不支持；现代感靠排版与配色 |
| `::-webkit-scrollbar` 自绘 | 系统原生滚动条 | 不可自绘 |
| `.rail` 左侧图标栏（设计稿未启用） | 未实现 | 设计稿本身 `display:none` |
| `sp-*` 控件 | **未使用**（返回键 / 按钮全自绘） | 见「刻意差异」§四 |

## 四、与设计稿的**刻意差异**（需要知情）

### 1. 交互：不照搬设计稿的右键菜单

| | 设计稿 | 本项目 |
|---|---|---|
| 设前景 | 左键（`mousedown`） | 左键（`click`） |
| 设背景 | **右键 → 弹菜单 → 选「设为背景色」** | **Shift + 左键** |
| 删除 | 菜单项 / **X 键** | **右键** 或 **✕ 按钮** |

理由：本项目既定交互已由自检 S3/S4/S6 覆盖；此次目标是**定视觉**，不动功能逻辑。
（用户明确：「可能与功能的实现逻辑不同，需要注意甄别，与本会话需求为准」。）
→ 若后续想改成设计稿那套，属于**功能变更**，需要重新走方案。

### 2. 全自绘，不再用 `sp-*`

`docs/13` 原计划「自写 CSS 为主 + 少量 `sp-*` 兜底」。落地时返回键改为**图标按钮**、存色按钮改为
**mini 按钮**，两处原 `sp-button` 都被自绘替代 → **本轮无任何 `sp-*` 依赖**。
代价：放弃「白拿主题跟随 + 无障碍」，改为自己用令牌实现主题。收益：视觉完全统一、无控件样式天花板。

### 3. 顶部品牌条用纯色

设计稿是 2px 蓝绿渐变；`linear-gradient` 在 PS 2024 / UXP 8.1 以下不生效，故改为 `--vt-ac` 纯色。

### 4. 字号整体 +1px（用户要求「不接受糊」）

设计稿 9.5–12px 承中文，在 Windows 下会糊。本版：正文 **13**、次级 **12**、最小 **11**。

### 5. 首页预览行用真实数据

设计稿首页每行右侧是假的纹理缩略图；调色板那行改为**显示 4 个真实品牌色块**，其余行显示状态灯。

## 七之补 · ⚠️ 上表已被真机实测修正（2026-10-10，见 `docs/16`）

这张表是**写代码之前**的猜测。真机跑完后，**结果和猜测差得很远**，
所以这里必须留一条显式更正 —— 否则后人会把猜测当结论用：

| # | 项 | 当时的猜测 | **真机结论（修正后）** |
|---|---|---|---|
| 1 | CSS 自定义属性 | 若不支持需大改 | ✅ **支持**（几何上实测宽 137px）—— 令牌体系稳 |
| 2 | `letter-spacing` | 「字距略松，其余无影响」 | ✅ **支持**（10px 字距差出 +100px）—— 设计稿的 `.06em` 字距一直有效 |
| 5 | `transform` | 若支持可换回 `translateX(-50%)` | ✅ **支持**（实测 +30px）—— 浮层可以用回 transform 了 |
| 11 | 布局测量 | 若不信需重做自检方法 | ✅ **支持**，但**必须让帧后再量** —— 见下 |
| 12 | `flex gap` | 若不支持需改 margin | ❌ **确认不支持** → `.is-first` + margin 方案**是对的**，继续用 |

另外补两条本轮才证实的：
- ❌ **`window.matchMedia` 在 UXP 里根本不存在**（不是返回 false，是 `is not a function`）
  → `@media (prefers-color-scheme)` 永远不生效，**主题只能靠 JS 挂 `.vt-dark` / `.vt-light`**
- ❌ **SVG 不做 `fill` / `stroke` 继承**（父节点写了也传不下去）→ 图标必须逐元素写属性

> 🔴 **最重要的一条教训**：这批「不支持」的结论里，**接近一半是量法错造成的假阴性**。
> 真因是 **UXP 的布局是异步的** —— 同步 `appendChild` 后立刻 `getBoundingClientRect()`
> 拿到的是尚未参与布局的 `0`，而不是「该特性不支持」。
> 判别过程与修正见 `docs/16` §四。探针现已带 **⓪ 基座自证**探针，基座失效时几何结论会自动标注「不可信」。
