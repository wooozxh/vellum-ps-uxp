# docs · 资料库与方案文档

本目录分两类内容：**参考资料**（别人写的、供查阅）和 **方案文档**（本项目自己写的、动代码前的确认依据）。

## 命名规则

- **`NN-xxx.md|html`** —— 统一编号，两位数字，空位不跳号
- **01 ~ 09 预留**：参考资料与通用方法论
- **10 起**：本项目自己的方案文档（一个功能模块 = 一份，动代码前必须先写）
- 中途插入的内容**不重排已有编号**（避免旧引用失效），按下一个空号往后排
