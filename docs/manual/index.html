PART ONE

装它

一个 .ccx 文件，双击，重启 Photoshop。这一章把装之前要确认的两件事、装完去哪找、以及怎么卸载都写清楚。

1.1这个插件是干什么的

它叫 Vellum 工具箱，是装在 Photoshop 里的一个面板（不是独立软件）。打开它，里面是一条竖着的功能列表：

工具一句话
调色板公司品牌色 + 你自己存的常用色。点一下就把颜色送进 PS 的前景 / 背景色，或者直接填满当前图层
素材库把「Vellum工作台」里的任务素材和通用素材，直接放到当前画布上
表格生成导入一个 CSV，在 PS 里生成一张能继续编辑的表格（一格一个文字图层），还能按行批量出稿
AI-MCP还没开放（见 2.7）

它不做什么

  • 它不管理文件。素材的增删改查全在「Vellum工作台」里做，插件只是把已经整理好的东西取过来用。
  • 它不动你的原文件。往画布上放素材时，插件拿到的是一份副本。
  • 它不上网。数据只在你本机硬盘上的插件目录里转，没有云端、没有账号。
和「Vellum工作台」的关系一句话：工作台负责"存和管"，插件负责"用"。两者装在同一个插件数据目录里对接，插件只读，写入永远由工作台做（见 3.1）。

1.2装之前：两件前提

要确认的事怎么确认
Photoshop 2024 或更高PS 菜单 帮助 → 关于 Photoshop 看版本号。低于 2024（v25）装不上 —— 插件在清单里就写了最低版本，PS 会直接拒收
装好「Vellum工作台」插件本身能独立工作（调色板、表格生成不需要它），但素材库那一格必须有工作台才有东西
先装哪个都行，但先开工作台会省事插件能自己找出工作台同步过来的数据目录；先装工作台并打开一次「插件联动」，插件装好后素材库立刻就是满的。反过来先装插件也完全没问题，只是素材库会先是空的。

系统要求：Windows 10 / 11 64 位。macOS 也能装，但本手册的截图与路径都按 Windows 写。

1.3安装（两条路：同事用 .ccx，开发机用 UDT）

插件打出来的安装包是一个 .ccx 文件（com.vellum.toolbox_PS.ccx）。它不需要数字签名，双击就能装 —— 这一点和老的 CEP 插件（.zxp，要签名）不一样。

路一：同事用这条（正式安装）

  1. 拿到 com.vellum.toolbox_PS.ccx，双击它。
  2. 等 Adobe 的安装器走完（系统会弹一个进度条，走完自己关）。装完文件落在 Adobe 的插件目录里，不需要你选位置。
  3. 把 Photoshop 完全退出，再重新打开 —— 插件是开机时加载的，不重启看不到。
  4. 按 1.4 的说法去菜单里把它叫出来。
"双击没反应"多半不是坏了Adobe 的 `.ccx` 靠 Creative Cloud 桌面版里的一个组件来装。如果这台机器从来没装过 Creative Cloud，双击可能什么都不发生。两个办法：① 装一次 Creative Cloud 桌面版（免费，登录不是必须）；② 改用下面的"路二"从开发工具加载。

路二：开发机 / 临时试用（UXP Developer Tool）

如果只是想先看看、或者在改插件本身，可以不打包，用官方的 UXP Developer Tool（简称 UDT，免费）直接加载源码：

  1. 装 UXP Developer Tool（Adobe 官方，随 Creative Cloud 一起装，或从 Adobe 官网单独下）。
  2. 打开它 → 点 Add Plugin → 选插件目录里的 manifest.json。
  3. 点 Load / Load & Watch，再回 Photoshop 把面板叫出来。
开发态和正式装是两套数据用 UDT 加载的那一份，数据存在 …\PluginsStorage\PHSP\<版本>\Developer\；双击 .ccx 装的那一份存在 …\External\。两边互不相通：开发态里存的「我的颜色」、看过的素材，切到正式版都是空的（反过来也一样）。同一台机器上如果两种都装了，PS 的插件菜单里可能出现两个同名面板 —— 建议只留一个。

1.4装完在 PS 里去哪找它

重启 Photoshop 之后，从菜单里叫它出来：

你要的去哪点
面板（主界面）菜单 窗口 → 插件 → Vellum 工具箱。它会以浮窗出现（约 420×680）；想固定就把它拖到 PS 右侧的面板区里停靠
三个快捷命令菜单里的 插件（有的版本叫 增效工具）→「Vellum 工具箱：品牌主色 → 前景色 / 背景色 / 填充当前图层或选区」
面板停在哪，PS 记不住PS 不允许插件自己声明停靠位置，位置只能你自己拖。拖好之后它会跟着工作区一起被记住 —— 但如果你是用 UDT 开发态加载的，位置不会被记住（这是 Adobe 的规矩，不是插件的问题）。
没在菜单里看到？按顺序排查：① PS 是不是真的重启过（完全退出，不是最小化）；② 帮助 → 关于 Photoshop 里的版本是不是 2024 及以上；③ 是不是装到了另一个 PS 版本上（机器上装了多个 PS 时，.ccx 只会装进它认识的那个）。

1.5第一次打开该看到什么

打开面板，第一屏是功能选择页：上面是插件名与版本，中间七行入口，最下面是「环境」——把当前 Photoshop 版本、UXP 版本、插件版本如实列出来，方便报错时截图。

点任意一行进入该工具，工具页左上角有一个返回箭头，点它回到这一页。页面底部那条状态栏是全局的：它会把最近一次操作的结果（成功 / 失败原因）如实写在左下角。

看到最后一行「⑦ AI-MCP」是灰的，是正常的它确实还没做（见 2.10）。其余六行都能点。

1.6更新 / 卸载 / 换电脑

更新版本

拿到新的 .ccx，直接双击覆盖安装即可，不用先卸载。装完一样要重启 PS。

更新会保留你的东西「我的颜色」、表格样式偏好这些都存在插件数据目录里，覆盖安装不动它们。

卸载

  1. 打开 Creative Cloud 桌面版 → 左侧 管理插件 / Marketplace → 找到「Vellum 工具箱」→ 卸载。
  2. 或者用系统的「添加或删除程序」：插件会以一条独立的项出现在列表里。

如果控制面板里删不干净（残留目录），可以手动删掉插件数据目录 —— 但删它等于把你的偏好一起删了：

手动删目录之前先想清楚插件数据目录在 %APPDATA%\Adobe\UXP\PluginsStorage\PHSP\<PS大版本>\External\com.vellum.toolbox\。里面有 PluginData\palette.json（我的颜色）、table-pref.json（表格样式）等。删掉不可恢复。另外这个目录也是「Vellum工作台」往里写素材镜像的地方，删之前先在软件里关掉插件联动。

换电脑

新电脑：装 PS → 装插件（.ccx 或 UDT）→ 装「Vellum工作台」并指向你的工作区目录。插件自己不存素材，所以没有什么需要搬的；只有「我的颜色」想带过去的话，把老机器上的 palette.json 拷到新机器同样的路径下即可。

PART TWO

八个工具

一页一个。每个工具都先说"它解决什么"，再逐块说明界面，最后给出边界（哪些它不做）。

目前只有 AI-MCP 还是灰的（没做）；其余七个都能用。

2.1首页：八个入口

首页是一竖排入口。每行左边是图标与一句话说明，右边是号位（↑1 ~ ↑7）和箭头。号位是固定的，报错时说"第 5 行"大家都懂。

行副标题要什么前提
① 调色板品牌色与我保存的颜色无。打开就能用
② 素材库任务库与通用库，一点置入需要「Vellum工作台」同步过素材
③ 表格生成表格绑定图层、批量出稿无。有一个 CSV 就行
④ 出图体检出图前先看清参数无。打开一张稿就能体检（2.7）
⑤ 导出审核版带参数条导出 · 改完自动还原无。打开一张稿就能导（2.8）
⑥ 新建稿从 PSD 模板建稿（参考线已打好）模板那半边需要工作台收录了模板（2.9）
⑦ AI-MCP把面板能力开放给 AI 客户端尚未开放

2.2调色板：品牌色与我存的颜色

解决的是"每次都要手输公司色的 HEX"。上面一块是品牌色（固定的六个，由开发维护），下面一块是我的颜色（你自己存的常用色）。

四种点法（面板底部也印着）

怎么点结果
左键把颜色设成 Photoshop 的前景色
Shift + 左键把颜色设成 Photoshop 的背景色
Alt + 左键直接填充当前图层或当前选区（不改前景 / 背景色）—— 想"啪一下铺满"用这个
右键 或角上的 ✕删掉这个颜色（只有「我的颜色」能删，品牌色删不掉）

顶部那两行是当前前景 / 背景色的读数（如 #E60012）。它是个"回执"：点完色块如果这里没变，就说明没设上。鼠标停在色块上也能看到它的 HEX。

存当前色 把当前前景色收进「我的颜色」（同一个颜色不会重复存）。

Alt+左键填充：形状图层 / 调整图层会拒绝填充只对像素类图层（普通图层、背景）有效。如果你选中的是一个形状图层、调整图层或者一个组，面板会直接告诉你原因，不会假装成功。想填它们，先栅格化，或者换个目标。
品牌色现在是占位色六个色块目前是占位值，等品牌 HEX 定稿后由开发一次性替换。「我的颜色」不受影响。

2.3素材库：素材从哪来、怎么翻

素材库不生产素材，它显示的是「Vellum工作台」同步过来的清单与缩略图。上面有两个库（页签）：

库装什么
任务库挂在某个任务下面的素材。按项目 → 任务分组，可以按项目筛
通用库不属于任何任务的常备素材（logo、字体、模板）。顶层是 公司素材 / 个人收藏，往下还能继续分层（最多 5 层）

怎么翻

  • 切库：点顶部 任务库 / 通用库 页签，右边的数字是该库的素材总数。
  • 进目录：页签下面那一列就是目录（📁 名字 …… N 项）。点任意一行往下钻一层，网格里就只剩这个目录的素材。
  • 回上层：钻进目录后，它上方会出现面包屑（如 通用库 › 公司素材），点任意一段直接跳回那一层 —— 不用一层层退。
  • 看大图：缩略图是瀑布流（保持原图比例，不裁切），所以长图和方图会混在一列里，高度不齐是正常的。
  • 手动刷新：右上角 刷新。平时不用点，它自己会刷（见 3.3）。

面板底部那条会写着现在看的是哪个库、多少张、筛的哪一层 —— 排查时先看它。

目录最多 5 层，超了会折叠目录层级由「Vellum工作台」那边决定。如果某一层子目录超过 3 个，剩下的会收成一行「还有 N 个」，点开才显示 —— 免得一进目录全是文件夹、看不到素材。
三段式：上面的目录、下面的置入条都不动只有中间那块网格在滚。所以素材再多，目录和「置入」也一直在原处，不用滑回顶部或滑到底部去找。根目录下看到的样子和旧版一样，只有真的往下钻了才会多出一行面包屑。
视频 / PSD / PDF 的缩略图可能是空白的这些格式取不到预览图，会显示一个灰色占位格。不影响使用，照样能放进画布。

2.4素材库：选中一张，放进画布

点一张缩略图选中它，面板最底下会出现一条详情，只有两行：左边是这张图是什么，右边是置入。

你会看到含义
文件名（第一行）名字太长会自己省略；鼠标停上去能看到完整文件名、磁盘路径、标签
尺寸 · 大小 · 角色 · 来源（第二行）来源是「公司」还是「我的」，后面跟着它在库里的目录位置
置入真的把图放进去。放的是副本，原文件不动

放进去落在哪

  • 画布上有选区：落在选区中心。
  • 画布上没有选区：落在画布中心。
落点九宫格已经去掉了以前选中素材会出现一个 3×3 的落点格子（左上 / 居中 / 右下……）。同事反馈几乎没人用，这一版删掉了，固定按上面两条规则落。要挪位置，置入后拖一下就行。
置入会把当前选区吃掉这是 Photoshop 的行为，不是插件的。所以"框哪儿放哪儿"的正确用法是：每次放图之前重新框一次选区。
详情为什么在底部放在底部以后它不会跟着网格滚走。以前在顶部时，素材一多就要滚回上面才能按「置入」；现在无论翻到哪，它就守在面板最下面那一条。
置入的图，大小可能和你以为的不一样PS 是按物理尺寸放图的：一张 300ppi 的图放进 72ppi 的画布，会按英寸换算，看起来"缩小"了。插件会按素材的像素尺寸尽量校正回原大小；但 PSD / PDF 这类拿不到像素尺寸的素材不校正，会保持 PS 给的样子 —— 手动缩放一下即可。
图层的名字会变成素材名置入后图层名取自素材名（去掉扩展名）；同名时自动加 (2)、(3)。智能对象内部记录的原始文件名改不了，那不在图层面板里显示。

2.5表格生成：CSV 变成图层

这个工具的产物不是一张"图片"，而是一堆可以继续改的图层：边框是细矩形、文字是普通文字图层。生成完你还能改字、改色、挪位置。

第一步：把表弄进来

  1. 点 导入 CSV，选一个 .csv / .txt / .tsv 文件。第一行默认当表头。
  2. 没有现成的 CSV？点下面那三个内置样例之一（UTF-8 / GBK / TSV）先试试手感 —— 它们就在插件里，不联网。

导入成功后，顶部会显示文件名与「N 行 · M 列」，下面一行写着识别到的编码。中间立刻出现表格预览。

中文 CSV 不用先转码插件自带 GBK 解码，UTF-8 和 GBK 都能直接读，Excel 另存为 CSV（默认就是 GBK）也能直接用。识别到什么编码会写在面板上。
Excel 换行 / 合并单元格会出事导出的 CSV 里如果有单元格内换行，可能被拆成多行。建议在 Excel 里先"另存为 CSV"再导入，别直接把 .xlsx 改名。

第二步：定"画在哪儿"（置入方式）

选项说明
用当前选区先拿选框工具在画布上框一块，表格就画在这块里（推荐：所见即所得）
落点锚不选区也能用：按一个预设尺寸（默认 420×320）生成表格框。画布很小时可能超出边界，面板会提示

第三步：样式（可跳过）

「样式」折叠块里有 通用 / 表头 / 行 三个页签：边框、底色、字号、文字颜色、行高表头高、内边距、列宽（等分或逐列改）。改完点 保存样式 会记住这套参数，下次打开还在。

第四步：生成

点 生成表格。生成完文档里会多出一个图层组，组名是「表格 · 文件名」，状态栏写着「✓ 已生成 …：图层 +N（预计 N），用时 X ms」。

图 2-7 里的棋盘格是 PS 的透明底这张表没填行底色（底色是可选项），所以除了表头那一块，其余都是"只有线和文字"。在 样式 里给「行」加个底色，它就会是一张带底纹的常规表。
格子越多，等得越久生成 51 个图层（5 列 × 6 行 + 边框）大约 3～7 秒；上百格要十几秒，而且文件会变重。大表先想想是不是真要在 PS 里做。面板每次都会先报预估层数。

2.6按行批量出稿：一张表套一个版式

这是表格页最下面那块。它解决的是：我有一张数据表，和一个搭好的版式，要出 N 份长得一样、只有内容不同的稿。（等价于 PS 原生的"图像 → 变量 → 数据组"，但那一套在 UXP 里调不到，插件自己实现了一套。）

怎么用（三步）

  1. 准备版式：在 PS 里搭一个图层组当模板 —— 里面放若干文字图层，每个文字层就是"将来被替换的位置"。
  2. 认模板：在画布上选中那个组，回到面板。面板会自动认出它并显示「将复制「组名」的 N 个文字层」。认错了就用「模板来源」手动指定，或点 重新检测模板。
  3. 绑列：表格里每一列是一行，每行三个选项 —— 「不绑定」或「第 1 / 2 / 3…个文字层」。把列绑到图层上（绑的是序号，不是名字）。

底部会实时算给你看：「N 份 × M 处文字（共 K 次写入）… 预估 ≈X s」。确认无误，点 生成 N 个稿件。

生成出来是什么

  • 模板组被复制 N 份（一份对应表里一行），名字自动起成「稿件 3 · 开学季特训营」这种带行关键词的名字。
  • 每份只替换你绑定的那些文字，其余保持模板原样。
  • 副本按网格自动排开（默认 5 列），不会全叠在一起。
  • 原件一根头发都不动。
现在只换文字，不换图模板里的图片图层会被原样复制，但不会按行换成不同的图。需要换图的话，得先把图做成可替换的格式，等后续版本支持。
格子里的空值会跳过表里某个格子是空的，那处文字保留模板原文（而不是被写成空白）—— 这比"写空"更安全，但你得知道有这个行为。
份数多会先问你一次份数或写入次数超过闸门时，第一次点按钮只是把它变成「仍然生成 N 个（约 X s）」，再点一次才真的开始。这样就不会手滑一下等十分钟。
名字里的"文本"是什么面板认模板时会列出组里的文字层（如「1. 标题」「2. 价格」）。这里的序号就是绑定用的序号；即使 PS 后续把副本里的层改名（"标题 拷贝"），照序号绑也不会错位。

2.7出图体检：出图前先看清参数

解决的是"发出去才发现是 RGB / 分辨率不够 / 字没转曲"。打开一张稿，点首页第 ④ 行，它会把这页稿的 12 项参数挨个查一遍，只读，不改图、不删层、不进历史。

三档结论

标记意思
合格这一项没问题（颜色偏绿）
提醒能发，但可能会被印刷厂打回来。比如 RGB 稿、150dpi、文字没转曲
无结论PS 没提供足够信息，插件不下判断 —— 不会假装合格

查哪些

色彩模式、分辨率、像素尺寸、物理尺寸、位深、颜色配置文件、文字图层是否转曲、字体是否都在本机、隐藏图层数、元素是否超出画布、出血、文档名与"有无未保存改动"。

它能查什么、不能查什么能查的：参数层面的问题（模式、分辨率、转曲、超出画布）。
不能查的：视觉层面的问题（好不好看、有没有错字、层级对不对）。
另外两项只给"疑似"：字体只能判断"在不在本机"，判断不了"选得对不对"；出血只能读到"有几条参考线"，读不到参考线的坐标（这是 PS 接口的限制）。
底部那行是"回执"体检完滚动到最底下，那行会写「体检完成（12 项）：N 项提醒」。0 项提醒不等于一定能发，只等于"参数这一层没挑出问题"。

2.8导出审核版：带参数条、改完自动还原

发给客户 / 领导看版时，最常被问的三件事：这是几比几的、多少 dpi、有没有出血。这个工具把答案直接印在图的底部，导出一张带参数条的审核图。

界面只有三块

区块说明
出血三个按钮：无出血 / 有出血 / 不确定。不确定会照实写进参数条，不瞎猜
出血量选「有出血」后才能改，默认 3mm
参数条预览这里显示的就是导出去的样子，配色 = 导出时的真实主题（深图用深条、浅图用浅条）

参数条上有什么

文件名 ｜ 导出时间 ｜ 色彩模式 / 位深 / dpi / 像素尺寸 ｜ 物理尺寸 ｜ 出血判定 ｜ 颜色配置文件 ｜ 文字是否转曲 ｜ 素材来源 ｜ 右上角「审核用 · 非成品」角标。

原稿一个像素都不动所有加条、缩放、转色彩模式的操作都打在副本上，导完立刻把副本关掉（不保存），然后切回你的原稿。所以导多少次都不会污染原稿 —— 也能解释为什么导完看历史记录是空的。
大稿会自动缩，并且把比例印出来长边超过 4000px 的稿会等比缩小后再导（否则看版的人打不开）。缩放比例会印在参数条上，避免有人以为看到的是 100%。成品图那条不缩、也不带参数条。
CMYK 稿会被转成 RGB 再导（只在副本上）PS 本身不支持把 CMYK 稿存成 PNG，所以导出前会先在副本上转成 RGB。原稿仍是 CMYK，不受影响。要交给印刷厂的文件请从原稿另存，不要用审核图。

PART THREE

它和「Vellum工作台」怎么配合

只有素材库那一格需要工作台。这一章说清"数据是怎么过去的"—— 弄明白这个，绝大多数"插件里没有东西"的问题就自己解释通了。

3.1数据是怎么过去的

不是"插件去连软件"，而是软件把清单写好，插件去读：

这个目录里躺着素材清单（manifest.json / task.json / brand.json）和缩略图。插件每 3 秒看一次它有没有变，变了就重新读一遍 —— 所以你在软件里改完东西，插件那边会自己跟上。

数据不出本机整条链路都在本机硬盘上，没有网络、没有云端、没有账号。「插件数据目录」这个叫法容易误解 —— 它就是本机的一个文件夹。

3.2软件里要开的两个开关

打开「Vellum工作台」→ 点顶栏的 插件：

开关说明
启用插件联动总开关。关掉之后插件里什么都看不到、也置入不了。平时保持勾上
分组上的 同步 开关通用库每个分组右边有一个。父组关掉，子组跟着关；「未分组」里的素材默认不过去 —— 想让插件看到，把它归到某个分组里
最常见的"插件是空的"三种：① 总开关没开；② 素材在「未分组」里；③ 那个分组的同步开关是关的。按这三条倒着查，基本一次命中。

设置项里还有一个「插件数据目录」。一般不用填：装好插件后软件会自己扫到并显示「已发现 N 个插件目录」。扫不到时才手填，或点 选择目录。

你做的事插件多久看到

PART FOUR

出问题怎么办

照着"现象"查。每条都先给最可能的原因，再给下一步动作。

4.1常见问题（照着现象查）

PS 的菜单里找不到「Vellum 工具箱」？

按顺序：① Photoshop 完全退出再打开过吗（不是最小化）；② 帮助 → 关于 Photoshop 里是不是 2024（v25）及以上；③ 是不是装到了另一个 PS 版本上（机器上多版本时容易装错）。

双击 .ccx 没有任何反应？

多半是这台机器没有 Creative Cloud 桌面版（`.ccx` 靠它里面的组件来安装）。装一次免费版 Creative Cloud，或者改用 UXP Developer Tool 加载源码（见 1.3 路二）。

素材库里一张素材都没有 / 少了很多？

三个开关问题，倒着查：① 软件里 启用插件联动 是不是勾着；② 那些素材是不是躺在「未分组」里（那里不同步）；③ 它们所在分组的 同步 开关是不是关着。都不对的话，在软件里点一次 同步到插件，看结果里的目录数是不是 0。

在软件里改了东西，插件里一直是旧的？

正常最多 4～5 秒（见 3.3）。超过 10 秒还不动，点一次软件的 同步到插件 强制刷。另外确认软件还开着 —— 关掉软件后插件就停在最后一次同步的样子。

置入的时候提示"取图失败"？

面板左下角会写清失败原因（比如 〔请求：scope=brand · id=59〕）。先确认「Vellum工作台」正在运行且插件联动是开着的；还不行就把那行字截图发开发 —— 那是能直接定位的原始读数。

置入进去了，但位置 / 大小不对？

位置：现在只有两条规则 —— 有选区落在选区中心，没选区落在画布中心（落点九宫格已经删了）。注意置入会吃掉选区，所以"框哪儿放哪儿"要每次重新框。大小：PSD / PDF 这类拿不到像素尺寸的素材不校正，会保持 PS 给的大小，手动缩放一下即可（见 2.4）。

点「批量出稿」提示"还不能出稿"？

看冒号后面那句："一列都没绑上" ⇒ 去绑定表把列绑到文字层上；"还没有模板" ⇒ 先在画布上选中你的版式图层组；"模板组里没有文字层" ⇒ 出稿靠换文字，模板里必须有文字图层。

一键填充（Alt+左键）说"当前不可用"？

你选中的是形状图层 / 调整图层 / 图层组。填充只对像素类图层有效。面板会明确说出是哪种图层挡住的 —— 看完再决定要不要先栅格化。

生成表格花了很久，PS 像卡住了？

格子多时（上百格）确实要十几秒，期间 PS 会短暂不接受操作，这是正常的。面板会先告诉你预估层数。如果超过一分钟没动静，看面板左下角的状态栏。

想把插件里的东西全部复位（颜色、样式偏好）？

删掉插件数据目录里的 palette.json / table-pref.json，再重启 PS。⚠️ 这是不可恢复的删除，动手前看 1.6 里的红框。
