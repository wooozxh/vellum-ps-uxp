01它到底是什么：三句话

一句话：给 AI 装了一双手，让 AI 直接在你打开的 Photoshop 里干活，而不是给你写一段你还要自己去跑的脚本。

  • 它靠 ExtendScript 通道（Windows 走 COM），所以不挑插件、不装扩展，只要 Photoshop 正在运行就能连上。
  • 它自带「状态感知」：get_state 读当前文档/图层/选区，get_preview 导出截图回读。 这是它比裸脚本可靠的根本原因 —— AI 能看见自己刚做了什么、然后自己检查对不对。
  • 它最值钱的是「配方」：把七八步操作打包成一次调用、一次撤销。做流水线时只该用配方，别一步步拼。
使用前提三条：① Photoshop 必须先开着；② 首次调用要等 30–60 秒（npx 冷启动下载）；③ 生成式功能（生成式填充/换天空等）需要登录 Adobe 账号、消耗积分。

0312 个真实场景：什么时候用它最省事

每条都写了「你原本要怎么做」和「现在可以直接说的话」。

1. 按名单批量出物料

recipe_csv_to_cards

工牌、会员卡、证书、邀请函、个性化 banner。做一个带变量绑定的 PSD 模板，其余交给一张 CSV。原来一张张改名字改工号改照片；现在表格填完就出图。

用这张 CSV 套工牌模板，出 200 张图到指定文件夹。

2. 批量样机套图

recipe_batch_mockup_replace

把同一批设计稿套进多个样机（或把多张稿套进同一个样机）。原来是逐个双击智能对象、换图、存、关；现在是文件夹进、文件夹出。

把 out 目录里这批图纸，逐个套进这个样机 PSD，导出全部效果图。

3. 一套稿出全平台尺寸

recipe_export_social_variants / recipe_split_carousel

主视觉一次成型，自动出微博 / 小红书 / 朋友圈 / IG 各规格。长图想切成轮播组图，一条指令切完并顺序编号。

这张主视觉出一套社媒规格；另外把这张长图切成 6 条竖图，按顺序编号导出。

4. 交付前统一规范

recipe_watermark + recipe_prepare_for_web

对外发之前批量压尺寸、转 sRGB、加锐化、盖水印。原来是开动作、跑批处理、还得盯着有没有漏文件。

这个文件夹里的图，全部转 sRGB 并压到宽 2000，右下角加这个水印，导出 JPEG。

5. 抠图与证件照

recipe_remove_background / recipe_passport_photo

去背是保留可编辑蒙版的非破坏性操作，不是"糊一层"。证件照自动去背 + 换底色 + 裁成标准尺寸。

把主体去掉背景，保留蒙版；再出一版白底证件照，一寸和两寸各一份。

6. 复用设计师已经录好的动作

play_action

这条被低估。部门里沉淀的 PS 动作（一键描边、批量锐化、招牌式的排版流程）不用翻译成脚本，直接点名播放。等于把老资产接入新工作流。

列出动作面板里有哪些动作；对当前图层播放「主图锐化」这个动作。

7. 稿子体检 + 一键整理

get_state + get_layers + recipe_organize_layers

接手来源不明的稿子：先读图层树看结构脏不脏（空层、乱命名、混模式），再按规范统一改名分组。比一个个点眼睛图标快得多。

读一下这个稿的图层结构，找出空图层和命名不规范的，整理成规范命名并分组。

8. 文案 / 素材改版

update_text_content + replace_smart_object_contents

活动已上线、文案要全量替换，或某个素材换新版。文字层替换会保留字体颜色对齐；智能对象替换会保留变换与滤镜。

把所有「立即抢购」改成「限时 5 折」，字体颜色别动。

商品图里去掉电线、路人、杂物；风景照换天并做地平线融合；小图生成式放大救急。注意生成式这几条走 Adobe 积分。

04用之前该知道的边界

  • 破坏性工具 43 个（删图层、拼合、改像素、替换智能对象、跑脚本、生成式…）。合理做法是统一包一层「预览 → 确认 → 执行」，且永远先对副本动手，别直接动源文件。
  • 纯只读只有 10 个（get_version、get_document_info、get_layers、list_fonts、get_selection_bounds、get_history、get_state、get_capabilities、list_datasets、list_artboards）。其余多数"轻副作用"（比如切换活动文档/图层），多文档时务必带 document_id，否则会误改别的稿子。
  • 超时不等于停止。报 extendscript_timeout 时 PS 里的脚本可能还在跑；正确做法是反复 ping 到成功，再用 get_state 恢复现场。
  • 暂存盘会拖垮它。报 scratch_disk_full 说明 PS 暂存盘快满（默认系统盘），清出空间并重启 PS，不是 MCP 的问题。
  • 它是社区项目，与 Adobe 无关；默认上报匿名使用统计（可关）。ping 成功后它会请求一次使用反馈，属正常行为，可以拒绝。

05建议的上手顺序

  1. 先开 Photoshop，然后让我跑一次 ping —— 通过说明链路就通了。
  2. 拿一张测试图，试两条：「去掉背景，保留蒙版」（验证单步精细操作）、「出一套社媒规格」（验证多步配方）。
  3. 确认好用后，直接上真正的痛点：第 1 条（CSV 批量出物料）和第 2 条（批量样机）。 这两条正好是「PSD 模板批产」的核心，也是这个项目 M2/M3 想做的事 —— 先用手上的 MCP 验证价值，再决定自研做哪一块。
和本项目的分工建议：这个 MCP 适合「一次性、AI 驱动、你盯着」的批量任务； Vellum 工具箱适合「固化下来、给设计部门同事天天点」的常驻能力（不需要开 AI 会话）。 两者不冲突：先用 MCP 跑通并沉淀出「正确的操作步骤」，再把这套步骤写成插件功能。
